# 求生者属性及队伍属性的确定

在对局中，求生者的破译属性、牵制属性、救援属性以及运营属性是四个重要的衡量对局中求生者能力的性质。这四个属性均在求生者的六维之中，但六维属性仅仅代表求生者本体的能力。事实上对局中求生者的某方面的能力是给予求生者本体的能力、天赋给予的能力以及选点的能力三方面构成的。

## 对局中求生者的能力构成

具体而言，这四个重要指标是这样构成的：

求生者的破译属性只与其本体的破译能力有关。

求生者的牵制属性与本体的牵制能力、牵制天赋的携带以及点位是否安全/易于牵制有关。

求生者的救援属性与本体的救援能力、飞轮效应天赋的携带以及化险为夷天赋的携带有关。

求生者的运营能力只与本体的运营能力有关。

## 队伍本体的能力构成

而对于队伍而言，破译属性、牵制属性、救援属性以及运营属性这四个指标同样重要。

队伍本体的属性完全由四名求生者决定。需要注意的是，队伍强调整体而非个体。即便某角色在某属性上具有较大能力，但其余角色在这方面能力不足，则队伍在这方面的能力也会相应的被降低。

## 对局中队伍的能力构成

需要注意的是，在对局中队伍的在某方面的能力除了与队伍本体的能力相关外，还与天赋选择以及区域选择有关。

具体而言，对对局中的队伍来说，这四个重要指标是这样构成的：

队伍的破译属性与队伍本体的破译能力有关，也与该选点的破译速度有关。

队伍的牵制属性可以认为是队伍中求生者的牵制能力的加权平均数，抗压位的求生者的牵制能力所占权值高，而其余求生者所占权值低。

队伍的救援属性与队伍本体的救援能力以及该地图是否利于救援有关系。

队伍的运营能力则与队伍本体的运营能力以及队伍整体所拥有的化险为夷的数量有关系。

## 对局的构成以及四个指标之间的联系

简单归纳的话，一局对局由三个部分构成：牵制、救援、运营。

简单来说，三者是从前期到后期的连续关系。首先是一溜牵制，其次是救援，然后是运营。

而它们之间的关系也可以简单的归纳为：牵制与救援是为了给破译和运营拖出时间。

简单来讲，牵制时间越长，破译的时间越长，破译的密码机进度更多，运营压力会减小。而救援天赋化险为夷则可以强行拖延时间，同样会留出更多的破译时间和运营压力。

# 天赋选择与区域选择的一般规律

**注意**：这里讲的是一般且通用的规律，对于角色或地图的特定部分需要进行更为具体的分析（这存放于角色数据以及地图数据中）。

如同上文所说，整局游戏的可以通过下面这句话总结：通过牵制与救援来为破译和运营拖出时间进而胜利。

这意味着天赋选择与区域选择的一般规律就是完成上述过程。而完成上述过程通常采用“均衡”的方法。

## 求生者个体层面上的天赋选择

求生者本体六维中总有较强的部分以及较差的部分。天赋选择和区域选择的核心思想是取长补短，做到均衡。

如果求生者的破译能力较强而牵制能力较弱，则考虑携带更多的牵制天赋保证牵制，从而避免因牵制不足而葬送对局。

如果求生者的牵制能力足够出众则可以考虑选择更多的运营天赋来为队伍做出贡献。

整体而言，只要做到“缺啥补啥，优势发挥”就可以很好的完成求生者个体的天赋选择。

## 队伍整体层面上的区域选择

队伍整体也是靠着类似的取长补短的均衡思路完成区域选择的。

如果队伍中某求生者的破译能力较强而牵制能力较弱，则考虑将该求生者放在安全位置，减少被追击的概率，发挥出快速破译的优势。

如果队伍中某求生者的牵制能力足够出众则可以考虑主动选择较为危险的点位来抗压。

整体而言，还是做到“缺啥补啥，优势发挥”就可以很好的完成队伍层面上的区域选择。
